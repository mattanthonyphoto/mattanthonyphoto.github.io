The Cost-Share Model

Most projects are cost-shared

On most projects, the architect, designer, and builder all need the same images. I coordinate a single shoot and split the cost between collaborators. Each firm licenses the images for agreed uses.

One shoot, split three ways, and every firm walks away with a complete set of images they will use for years.
